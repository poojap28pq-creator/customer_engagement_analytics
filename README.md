# Customer Engagement & Product Utilization Analytics for Retention Strategy

## Project Overview
This project focuses on analyzing customer engagement and product utilization patterns in the banking sector to identify churn-risk customers and improve retention strategies using Machine Learning and Streamlit.

---

## Objectives
- Analyze customer engagement behavior
- Identify churn-risk customers
- Predict customer churn using Machine Learning
- Generate retention strategies
- Build an interactive Streamlit dashboard

# Streamlit App Execution

## Steps to Run the Application

### Step 1: Open Terminal or Command Prompt

Navigate to the project folder:

```bash
cd customer_engagement_analytics
```

---

### Step 2: Install Required Libraries

```bash
pip install -r requirements.txt
```

---

### Step 3: Run the Streamlit Application

```bash
streamlit run app.py
```

---

## Application Execution Flow

1. The Streamlit server starts locally.
2. Customer banking dataset is loaded into the application.
3. Pre-trained Machine Learning model (`model.pkl`) is loaded.
4. Interactive dashboard opens in the browser automatically.
5. Users can navigate through different analytics pages:
   - Home
   - Engagement Analytics
   - Product Utilization
   - High-Value Disengaged Customers
   - Retention Strength
   - Churn Prediction
6. The system performs:
   - Customer analytics
   - Churn prediction
   - Retention score generation
   - AI-driven retention recommendations
